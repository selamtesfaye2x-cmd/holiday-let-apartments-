StayHaven

StayHaven is a holiday-let and rental property listing platform.

Features

- User registration and login
- Owner dashboard
- Add and manage property listings
- Holiday lets
- Short-term rentals
- Long-term rentals
- Booking requests
- Booking management
- Supabase authentication and database

Technology

- JavaScript
- Supabase
- GitHub Pages
